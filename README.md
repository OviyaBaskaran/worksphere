# WorkSphere — Employee Management System

WorkSphere is a full-stack Employee Management System built with React.js, Node.js, Express.js, MySQL, and Cloudinary.

## Features

* Admin authentication using JWT
* Employee management with CRUD operations
* Department management
* Dashboard with employee statistics
* Employee search, filtering, and pagination
* User profile management
* Profile and employee image uploads using Cloudinary
* Responsive user interface
* REST API integration
* Frontend and backend separated into independent applications
* Deployed frontend using Vercel and backend using Render

## Tech Stack

### Frontend

* React.js

### Backend

## Application Architecture

```text
React.js Frontend
       ↓
     Axios
       ↓
Express.js REST API
       ↓
Service Layer
       ↓
    MySQL
```

Cloudinary is used for image storage and management.
